# Changelog

All notable changes to this package are listed here. The project follows [semantic versioning](https://semver.org).

## 0.1.1

- Published with npm trusted publishing from GitHub Actions. No changes to the library.

## 0.1.0

First release.

- SMS API: messages (send, bulk, get, list), batches, sender IDs, wallet, pricing, stats.
- OTP API: send and verify.
- Bappy API: Links, plans, SMS, transactions, organization, info.
- Phone Numbers API: search, preview, purchase, numbers, orders, bulk orders, endpoints, SMS, KYC, porting.
- Webhooks: signature verification with typed events, and signing for tests.
- Automatic access tokens, idempotency keys, safe retries and pagination.
